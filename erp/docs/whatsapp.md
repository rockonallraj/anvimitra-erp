# WhatsApp Business API Integration

## Messaging Channels
Anvi Mitra ERP dispatches automated transactional messages for:
- Student absent alert (sent 15 minutes after morning attendance lock).
- Fee payment reminders & digital receipt links.
- Report card publishing announcements.
- Admission enquiry follow-ups.

## API Integration
The `/api/communication/whatsapp` endpoint interfaces with WhatsApp Cloud API using pre-approved HSM templates to ensure compliance with Meta policies.
